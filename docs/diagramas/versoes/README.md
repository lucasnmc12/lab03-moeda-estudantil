# Versões da modelagem

A pasta `sprint1/` preserva os três arquivos PlantUML da modelagem inicial. As imagens correspondentes e os demais artefatos dessa etapa estão na tag Git `sprint1`.

A tag `sprint2` preserva o ER, a migração inicial e os CRUDs antes da integração dos fluxos de moedas. A tag `sprint3` identifica a entrega final. O modelo corrente em `docs/diagramas/` acompanha o código final. Alterações e suas origens estão em `docs/REVISOES.md`.

As tags representam marcos desta execução, com datas reais, sem simular semanas ou apresentações anteriores.
